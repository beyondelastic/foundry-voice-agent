# Music

Drop your own audio files here, named after the playlists:

- `calm.mp3`
- `focus.mp3`
- `upbeat.mp3`

They loop while the playlist plays. If a file is missing, the UI falls back to a small
generative synth, so the demo works without any files.

Only use music you have the rights to, for example royalty-free or Creative Commons tracks
whose license allows this kind of use, or your own recordings.
The files are ignored by git, so they are never committed to the repo.
